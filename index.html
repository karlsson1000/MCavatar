MCavatar

Avatars, skins, body renders, and UUID lookups for any player.

Base https://avatar.mcindex.net/
User username or UUID e.g. Dinnerbone or 61699b2e-d327-4a01-9f1e-0ea8c3f06bc6

Avatar

Player face with hat layer, rendered at the requested size.

https://avatar.mcindex.net/avatar/user copy
https://avatar.mcindex.net/avatar/user/128 copy

Optional size in pixels.

Body

Full front-facing body render.

https://avatar.mcindex.net/body/user/128 copy

Size in pixels (height). Width scales proportionally.

Bust

Head and torso cropped render.

https://avatar.mcindex.net/bust/user/128 copy

Size in pixels.

Skin

Raw skin texture as a PNG.

https://avatar.mcindex.net/skin/user copy

Returns the original 64×64 skin file.

UUID Lookup

Returns the player's username and UUID as JSON.
